## 고치는 법

사이트의 문서 제목 옆 **고치기**를 누르면 그 자리에서 편집기가 열린다. 고쳐서 저장하면
GitHub에 커밋되고 워크플로가 사이트를 다시 만든다.

처음 저장할 때 GitHub 토큰을 한 번 넣는다. github.com/settings/personal-access-tokens 에서
이 저장소만 대상으로 Contents 읽기·쓰기 권한을 준 토큰을 만들면 된다. 토큰은 브라우저의
localStorage에만 저장되고 api.github.com 외에는 전송하지 않는다. 목차 아래 **토큰 지우기**로
언제든 지울 수 있다.

저장은 문단 단위다. 저장 직전에 원본 파일을 다시 받아 해당 문단만 바꾸므로, 다른 사람이 먼저
고친 다른 문단을 덮어쓰지 않는다.

문서는 `content/` 아래 Markdown 파일이다. 파일 하나가 모듈 하나이고, `## ` 제목이 왼쪽
목차의 항목이 된다. 앞부분 머리말에서 번호와 난이도를 정한다.

```markdown
---
id: m1-foundations
no: "01"
title: HPC 기초
subtitle: 클러스터의 구성과 작업 실행 경로
level: 입문
---

모듈 도입부.

## 첫 번째 절
본문.
```

그림은 `assets/img/`의 SVG를 쓰고 `![설명](img/파일명.svg)`으로 넣는다. 모두 직접 그린
것이다.

## 빌드

```bash
pip install markdown
python build.py        # content/*.md -> site/
```

## 어투

문서는 `-다` 평서형으로 쓴다. 존댓말과 1인칭을 쓰지 않고, 과장 형용사와 요약 라벨을 넣지
않는다.
